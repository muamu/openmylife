# 去 AI 味 · 句式清单与改写示例

> 配合 [SKILL.md](../SKILL.md) 使用。这里是「红灯清单」：命中不代表有罪，只代表值得看一眼。

---

## 1. 七种高频句式

| # | 句式 | 为什么扎眼 | 怎么改 |
|---|---|---|---|
| 1 | 「不是 A，而是 B」 | 先立靶再翻案，一篇里出现多次就像模板 | 直接说 B；确实需要对比时保留一次 |
| 2 | 「真正的 X 是 Y」 | 「真正」多半可以删 | 删掉「真正的」，或换成具体名词 |
| 3 | 「更关键的是 / 值得注意的是」 | 连接词在替读者做判断 | 直接写事实，让读者自己判断 |
| 4 | 「这意味着 / 换句话说」 | 把同一句话再说一遍 | 说结果，不复述 |
| 5 | 段末设问 | 「那么，问题来了？」式收尾 | 删掉问句，或把答案写出来 |
| 6 | 三连排比 | 「既要 A，也要 B，还要 C」 | 改成两项或四项，长度不要一致 |
| 7 | 结论提示冒号 | 「答案很简单：……」 | 直接给答案，去掉提示 |

## 2. 结构层的高危动作

| 动作 | 例子 | 处理 |
|---|---|---|
| 每节都用「现象—原因—结论」 | 六节结构完全一样 | 至少两节换写法：只讲案例、只给数、只提问 |
| 自造分类当小标题 | 「三张执照」「四层地图」反复出现 | 第一次出现前先讲事，全文最多两次 |
| 段末必须点题 | 每段最后一句都是短句金句 | 删掉一半，剩下的并回段内 |
| 结尾升华 | 「这，才是真正的开始」 | 换成一句具体的、可能不圆满的话 |
| 对称版式 | 三列卡片、三个指标、三条判断 | 保留版式可以，但每条字数与句式要不一样 |

## 3. 改写示例

**例 1 · 开头**

- 改前：这个月最值钱的两条新闻，都不在「产品」上。
- 改后：先说两笔钱。一笔 9000 万美元，一笔 450 万；买的都不是「助理」。

**例 2 · 段尾**

- 改前：这就是为什么，通道卖的是「到达率」，不是「聪明程度」。
- 改后：通道这层先赚钱的，是修路的，不是做助理的。（或直接删掉，让上一句事实停住）

**例 3 · 收束**

- 改前：有人在修路，有人在发通行证，有人在保管记忆，也有人在为每一次调用付算力钱。
- 改后：Linq 和 Photon 在修路，Poppy 在写门规，Second 在保管记忆。至于最后谁靠这个挣钱，账单还没出来。

**例 4 · 判断**

- 改前：这不仅是技术问题，更是商业问题。
- 改后：技术上能做，卡住的是商家愿不愿意开门。

**例 5 · 不确定**

- 改前：可以预见，未来这一层将形成新的标准。
- 改后：这一层现在没有标准，连该由谁来定都不清楚。

## 4. 允许保留的「AI 常用词」

下面这些不必一律删，关键看频率与上下文：

- 破折号：中文本来就在用，密度正常即可。
- 引号包概念：术语首次出现需要引号，重复时不必再加。
- 「其实」「当然」「不过」：口语连接词，适度使用是好事。
- 冒号：列举、定义、引语都需要它，别为了去 AI 味绕成病句。

## 5. 计数命令（PowerShell，只读）

```powershell
$p = "path\to\article.html"
$t = Get-Content $p -Raw
foreach ($w in @('说白了','真正','本质','核心','不是','而是','值得注意的是','更关键的是','换句话说','这意味着')) {
  $c = ([regex]::Matches($t, [regex]::Escape($w))).Count
  if ($c -gt 0) { "$w : $c" }
}
```

看两个数就够：**「而是」的次数** 和 **「说白了」的次数**。前者超 2、后者超 1，基本就要回头改。

## 6. 朗读测试

1. 出声读第一屏（标题、导语、前两段）。
2. 读着要换气的地方 → 拆句。
3. 读着像念稿的地方 → 换成自己会说的词。
4. 读着没有信息的地方 → 删。

读顺了再谈风格；读不顺，词换得再花也没用。

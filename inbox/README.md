# inbox · 收件箱（素材暂存）

> **本目录里的内容默认不公开。** 只有本文件会被提交，其余一切都被 `.gitignore` 挡在仓库之外。

## 这是什么

「随手丢素材」的地方。任何还没想好归哪、还没脱敏、体量大的东西，先进这里 —— 不分类、不命名、不求好看。

## 怎么用（三步）

1. **随手丢**：素材、草稿、截图、对话记录，先扔进来。零摩擦是它唯一的价值。
2. **定期清**（建议每周 1 次，与更新节奏同步）：
   - 值得公开 → 按 [CONTEXT.md](../CONTEXT.md) §3 的命名约定，移进 `notes/` / `critiques/` / `stories/` / `ideas/`
   - 有隐私风险 → 走隐私门，`never` 级**直接删**
   - 不需要 → 删
3. **目标状态是空的**：inbox 是中转站，不是仓库。它空着，说明你在正常出货。

## 为什么内容不公开

- 原始素材常含**他人隐私、未脱敏信息**（聊天记录、截图、他人姓名）
- 常含**大体积文件**（视频素材、zip），不该进 git 历史
- 公开仓只放「整理好的作品」——**过程垃圾不对外**

> 与 `ideas/` 的分工：`ideas/` 是**已经愿意公开**的随手记；`inbox/` 是**还没决定**的原始素材。

## 实现注意

- `.gitignore` 里用的是 `inbox/*` + `!inbox/README.md`（**不是** `inbox/`）——否则本文件自己也会被挡掉、无法提交。
- 若你确实想让整个目录都不公开，把规则改成 `inbox/` 并删掉本文件即可；代价是 fork 你的人学不到这套工作流。

先说这两笔钱

先说两笔钱。一笔 9000 万美元，一笔 450 万；买的都不是「助理」。

Linq 这轮拿了 a16z 领投的 9000 万美元，估值 10 亿美元，Ben Horowitz 进了董事会。今年 2 月它才刚完成 2000 万美元的 A 轮，十个月不到，估值翻了几倍。它做的业务不看名字的话，很容易被当成一家通信公司：让 AI 像普通联系人一样躺在你的通讯录里。用户不用下载 App，iMessage、短信、WhatsApp 随便哪个都能找到它；开发者那边，把自家 Agent 通过接口接进这些渠道即可。DoorDash 已经用上了——顾客在苹果的商务消息里挑餐、加购物车、结账，整个过程不跳出聊天窗口。它还给 AI 配了 HD Calling，能直接拨打和接听高清电话；另外提供托管的 Mac mini，让 AI 远程操作浏览器和 macOS 软件，Kernel 是第一批客户。

Photon 的种子轮只有 450 万美元，由 Gradient 和 A* 共同领投。它怎么挣钱？一条 Business 线路 250 美元/月，大概覆盖 200 到 400 个终端用户。做的事比 Linq 更靠底：给每个 Agent 分配一个手机号和邮箱，让它可以接进 iMessage、WhatsApp、邮件和电话。按公司口径，5 月到 8 月收入涨了 10 倍，单月消息量翻了 5 倍，流失率低于 3%，注册开发者超过 5 万。

我一开始以为这两家是竞品，看完业务说明又觉得不太对。Linq 更偏「前端」：怎么让 AI 出现在你已有的聊天入口里，还能打电话、操作电脑；Photon 更偏「管道」：号码发下去，消息进出、路由、计费都由它管。客户名单有重叠，比如 Instinct 和 Manus，但两家卖给开发者的东西不太一样。

Photon 的联合创始人 Ryan Zhu 有个判断，被很多报道引用：五年后没人会专门打开一个 ChatGPT App 提问。这个判断对不对另说，但它至少解释了一件事——这半年钱为什么都往通信层跑，而不是往又一个助理 App 跑。

这篇在讲什么

如果只记一件事：竞争已经从「谁的助理更聪明」，挪到了「谁有资格替用户出面」。具体拆成三块——它怎么找到人（通道）、别人怎么认它（通行证）、它凭什么一直懂你（记忆）。后面几节按这个顺序讲，最后两节讲代价和我会看的数。

01

AI 开始从短信里找你

「不用装 App」听起来只是省了一步安装，实际上是换了关系：从一个「你要记得打开的产品」，变成「通讯录里本来就有的一个人」。

Photon 最早是周末黑客松的产物。联创把自己全部的 iMessage 记录喂给模型，再把生成的内容接回 iMessage，做了个模仿自己的自动回复机器人，把朋友骗着聊了好几天。工具开源后，一晚上来了几千名开发者。后来真正把它做成生意的，是另一个判断：人不会为了 AI 重新学一套交互，只会把 AI 拉进已经用了几十年的短信和电话里。

这条道不好修。协议兼容、自建机房、对接运营商，还要合规持有海量手机号，任何团队从零搭一套，都要 6 到 8 个月。模型三个月一迭代，这半年就是实打实的差距。所以连大厂也用第三方方案，不是做不出来，是等不起。

这个月，几乎所有人都在往这条道上挤。Google 把 Spark 改名 Tasks，向六个国家的免费用户开放，能直接发短信，也能把邮件转发到 gemini@google.com 让它办事；还能同时拨打好几家店，问价、查库存、预约。Anthropic 把 Claude Duet 的美国候补名单放完了，但它在后台巡邮件、扫日历同样烧额度，和 Claude Code 共用配额——像员工一样上班，也像员工一样计费。Meta 的 Muse 已经在用 Poppy 认门。Instinct 做得更彻底，连 App 都没有，只有短信和电话。

但通道不等于需求。Photon 站在所有消息的必经之路上，看到的几件事不太体面：Agent 发出去的消息，用户回得不多，很多人试一两周就不玩了；工作日忙、周末冷，周日尤其安静；号称的「主动性」大多是定时推送，本质还是个通知机器人。用户也会在产品之间跑，但每家都能留下几个重度用户——最黏的是陪伴类，「AI 男友 / 女友」的留存和图片、语音交互高得离谱。

9 月它在一座教堂办了场「App Funeral（App 葬礼）」，主张用户拒绝安装新 App，Agent 就应该待在人们每天点上百次的原生对话框里。活动当然有营销成分。不过它提的那个阻力是真的——手机上多一个图标，就多一次「算了吧」。

02

商家开始自己写「怎么进门」

V4 里我写过几道门：亚马逊拦 Muse、豆包 SAEP 被 150 多款 App 书面拒绝、小红书连「只浏览」都判违规。这个月出现了一个不太一样的做法。

Meta 和 Sierra 一起推的协议 Poppy 发了 1.0。它的思路很笨，但管用：商家公开一份接入说明，AI 读到就知道——这儿有哪些服务能调用、怎么登录、需要用户授哪些权限。接上之后，AI 可以直接调商家的 API，也可以跟商家的客服 Agent 对话，不用一遍遍开网页、点按钮。Shopify 更进一步，替平台上几百万商家把接入文件自动发了出来，店主不用做任何事；它还把 Poppy 和购物协议 UCP 接上，Poppy 管「你是谁、能不能进」，UCP 管搜商品、加购物车、结账。

和之前两条路比，这条路最实际的变化是：商家第一次不用和每家 Agent 公司单独谈判。装成人去租真机、模拟点击，技术上能跑，但平台一判违规就封号；求接口要一家家 BD，谈成几家算几家。Poppy 把门规写成文件，谁读都一样，成本从一个一个的合同，变成了一份可以被机器读懂的说明。

支付也在往这个方向走。OpenAI 同一天推出 ChatGPT Wallet：dot 帮你跨店比价、提前备好结账信息，付款那一刻仍要你本人按指纹，商家只拿到一张一次性的卡凭证。Mercury 允许 AI 查余额、整理交易，甚至发起转账，但资金划转仍需账户审批；土耳其航空允许 AI 查航班、调预订、找升舱机会，用户确认后才付款。现在有 60 家企业加入 Poppy 的设计，包括 Salesforce、Zoom、达美航空，合作伙伴超过 100 家。

03

把记忆从 App 里拿出来

一个人用三个 AI，就得把同一段背景讲三遍。Second 想解决的就是这个。

Second（First Person Labs）拿了 a16z 领投的 1000 万美元种子轮。它装在 Mac 上，后台持续读取电脑活动，自动整理你正在做的项目、待办、联系人、写作习惯，以及几分钟前做过什么。用久了，它会慢慢摸清你的偏好、工作方式和优先级。关键设计是它不绑任何一家模型：通过 API 和 MCP，把同一份记忆给不同 Agent 用——你在 Claude 里聊的项目，切到 Codex 写代码，或者换 Grok Bot 接着做，都不用重新讲背景。这些记忆默认放在本地文件夹，你能查看、修改、备份、迁移，也能决定哪个 AI 有权限读。

类似的想法不止一家。Dazzle 切的是手机相册，提出「这条信息用不上，就主动忘掉」；有团队在做把截图整理成情绪板的产品，写代码时可以直接调用个人风格档案；还有新 Agent 用一通语音电话冷启动，人在电话里容易放松，背景就顺着聊出来了。a16z 圆桌上，David 让榜单前 15 名 Agent 把记忆导出成 Markdown，14 个照做。但读完这些文件的人都有点不舒服，原话是「它把我看得太透了，甚至超出了我希望被了解的程度」。

国内也有类似的想法：把记忆做成第三方系统，像 iCloud 一样保管，用户每月付 200 块，哪家 Agent 不好用就换。但真要做，有四道坎——什么该存、什么时候存、长短期怎么划分，全都取决于各家的 Agent 框架；行业还没有统一的数据结构；「授权」和「记忆」是两套逻辑，很容易混在一起；最现实的是，用得越久，越懂你的那个就越难走。

资本也在押这个方向。前复星锐正合伙人刘方未加入 Today AI 当联合创始人。她 2014 年代表盘古创富投过齐俊元创办的 Teambition，隔 12 年又上了同一条船。Today 主打长期记忆、主动提醒和跨应用执行，今年累计融资已经超过 2 亿美元。

有个矛盾

记忆越可携带，越像一份属于你的资产；但它同时也是一份可以被拷走的档案。Second 把默认位置放在本地文件夹，算是站了队；可导出之后各家的格式能不能互通，不是一家公司能定的。这件事现在没有标准，连该由谁来定都不清楚。

04

会办事，不等于会看场合

授权能不能持续，很多时候不取决于它办没办成，而取决于它有没有在该闭嘴的时候闭嘴。

Assistant Benchmark 的创建者 David 做了两组实测。第一组是「给女朋友买花」，硬要求是当天送到、越便宜越好。多数 Agent 能保住时效，但在价格上让步；只有 Instinct、Kicker、Season 把「快」和「便宜」看得差不多重。第二组是「洛杉矶过周末顺便订机票」，偏好是故意打架的——又要奢华又要高性价比。Dots 直接排红眼航班省钱，Grokbot 把「时间」当成奢华、尽量让你在洛杉矶待满，Instinct 在中间折中。更高一层的答案不是二选一，而是把矛盾拆开：坐红眼省钱省时间，落地先开间房补个觉，多花一点换一整天精神。

他还把 Grokbot、Dots、Instinct 拉进同一个聊天室，让它们互相辩三轮。结果只有 Grokbot 把别人方案里的好东西吸收进了自己的计划。这件事比分数有意思：会办事的 Agent 很多，能在一堆互相打架的要求里给出第三种答案的，没几个。

比会办事更难的，是看场合。一份 3600 条消息的用户群里，大家最担心的排第一是「信任」，占了相关讨论的 22%。真正让人收回授权的，往往还不是钱。有创业者的 Agent 把他的财务信息发进了公司 Slack；有人担心第二次约会时，两边的 Agent 已经在后台交换信息，「它到底会怎么描述我」；还有人举了个更小的例子——你和朋友一起领免费披萨，你不吃奶酪，这话该由谁的 Agent、在什么时候说。这种尴尬，比丢几十块钱吓人多了。

“消费者嘴上特别在乎隐私，真到做选择的时候，却愿意拿一大堆隐私去换一点点方便。” a16z 圆桌《The New AI Agents That Shop, Plan, and Gossip》· 2026-11-04

证据是 Hark 那笔 100 万美元的营销：请人免费吃披萨、每人补 30 美元，条件是授权访问整个 Google Workspace，所有邮件和文档。结果一大堆人乐意。用户算的账，和产品经理算的不是一本：省下的钱看得见，丢的面子也看得见，而后者更影响下一次授权。

05

有个不太好听的账

证发得热闹，拿到证的人不一定赚钱。这半个月我看到最具体的一笔账，来自一位做过 Personal Agent 的创业者。

他给每个用户配了一台云端虚拟机，让 Agent 真像人一样开软件、调工具。跑了一段时间，财务模型崩了：一个月从每个用户那儿收来的钱，只有背后算力、token 和云资源成本的 1/4。更要命的是，他想不清楚到底沉淀下了什么别人拿不走的东西。另一位一开始就想做全能的 Personal Agent，很快发现数字环境和物理环境对 Agent 都太不友好——页面一变、权限一限、任务一断，它就得重试、补上下文，token 和云资源哗哗地烧。

不是孤例。Dots 定价 $100/月，市场估算服务一个这样的用户，每个月要烧约 $3,000 的算力；Photon 的增长数字好看，可它自己承认用户回得少、试一两周就走。a16z 圆桌的现场更直白：150 位参会者把各自的 Agent 丢进同一个公共聊天室，大概 150 条消息之后，有些 Agent 开始胡言乱语，输出乱码。多 Agent 社交网络离规模化还远。

国内在试另一个方向。千问办公 2.0 把数字员工小Q 放进团队协作空间：关联钉钉群聊、听记、表格和文档，经 IM 接活，纯云端任务关机后也能跑。个人助理的下一站，可能是「团队里也留一个 Agent 的位子」；不过这也把权限问题从一个人放大到了一个群。

一个自检

Photon 有句话，我觉得可以拿去问所有做这行的人：如果你的服务今天突然宕机，会有多少客户在一秒钟内打电话过来？我觉得这个问题比看日活有用。通道、通行证、记忆这三层，谁卡住了必经之路，谁就能收租；应用层如果一层都没攥住，就只能一边烧算力，一边给基础设施交过路费。

06

我会看哪三个数

这三个数不好看，也不适合放进发布会，但比日活更能说明问题。

01
代理权覆盖率
高频的事里，有多少次真是它代表你去谈、去买、去约，而不是它给个建议、你自己上手。Poppy 和 Wallet 出来之后，这个数第一次能从商家那头统计。
02
授权可携带性
记忆和授权能不能带走。Second 把记忆放本地文件夹、15 个 Agent 里 14 个愿意导出 Markdown，都是好信号；反面是断开连接之后，已经留下的记忆删不掉。
03
单次代理返工率
办错、越权或被拒之后，多久能恢复。Trusted Completion、迅宝的回执、沃尔玛的消费上限、Poppy 的权限声明，都是在压这个时间。

它们合起来，回答的是一个很具体的问题：用户交出去的那部分决定权，有没有被稳妥地用，出错了能不能收回来。日活只能说明它被打开过。

写到最后

V3 我关心上下文归谁，V4 关心默认值站哪边。到了 V5，问题是它凭什么代表我去跟别人打交道。

这个问题现在没有答案。能看出来的只有分工：Linq 和 Photon 在修路，Poppy 在写门规，Second 在保管记忆。至于最后谁靠这个挣钱，账单还没出来。

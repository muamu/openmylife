# 个人助理 V5 洞察：AI 想替你出门，得先有人给它开门

> 基于《国内外生活助理类 AI Agent 产品清单 v5》的更新洞察：这半个月的钱和协议，大多花在「让 AI 能被别人接受」上——Linq 修通道、Poppy 发通行证、Second 保管记忆。三件事凑齐，它才算真的能替你出门。完整内容见 [index.html](./index.html)。

- **材料**：[《国内外生活助理类 AI Agent 产品清单 v5（2026-11-19）》](../2026-10-life-assistant-agents/index.html)；线上站点版 [personal-agent.html](https://openmylife.xyz/articles/agent/personal-agent.html)
- **核心论点**：竞争从「谁的助理更聪明」挪到「谁有资格替用户出面」；通道、通行证、记忆三层里，谁卡住必经之路谁收租，应用层一层都没攥住就得替基础设施交过路费
- **关键证据**：Linq 9000 万美元 B 轮、估值 10 亿美元；Photon 按 250 美元/线路/月收费、Personal Agent 占其客户 40%–50%；Poppy 1.0 让 Shopify 数百万商家自动发布接入文件；Second 1000 万美元种子轮、记忆默认存本地文件夹；a16z 圆桌「信任」占 3600 条讨论的 22%；Founder Park 访谈里单用户收入仅为算力成本 1/4
- **三个替代指标**：代理权覆盖率、授权可携带性、单次代理返工率
- **线上版本**：[个人助理 V5 洞察](https://openmylife.xyz/articles/agent/personal-agent-v5-agency.html)
- **数据口径**：融资与用户数多为公司公告与访谈口径，未经审计；Dots「$3,000 算力」为市场估算；「收入为成本 1/4」为受访创业者自述、样本单一；详见 [index.html](./index.html) 文末「数字口径提醒」

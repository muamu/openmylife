# 个人助理 V3 洞察：从抢入口到抢上下文

> 基于《国内外生活助理类 AI Agent 产品清单 v3》的更新洞察：V3 真正新增的不是五个产品，而是三种生产、保管与定价个人上下文的方式。竞争重心从「谁先做出能办事的助理」，转向「谁能持续生产、保管并定价你的上下文」。完整内容见 [index.html](./index.html)。

- **材料**：[《国内外生活助理类 AI Agent 产品清单 v3（2026-11-08）》](../2026-10-life-assistant-agents/index.html)；线上站点版 [life-assistant-agents.html](https://openmylife.xyz/articles/agent/life-assistant-agents.html)
- **核心论点**：上下文的三道工序——**生产**（Elys 社交网络 / Boba 群聊 / Moras 垂直工作流）、**保管**（灵光 APASS 密钥分离、迅宝人工闸门、Oki 本地加密卡、沃尔玛 Agent Profile）、**定价**（卖结果而非卖入口）
- **关键判断**：能力已变成供应链（Hark Pro 四家模型混用）；下一阶段看三个指标——授权深度、分成率、可携带性，不看 DAU

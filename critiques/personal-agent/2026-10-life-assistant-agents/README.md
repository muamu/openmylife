# 国内外生活助理类 AI Agent 产品清单（v5 · 2026-11-19）

> 国内外生活助理类 AI Agent 的产品地图：国际 26 个、国内 17 个、手机厂商自带 5 家、硬件 4 个 + 边界样本 1 个，另附评测榜、基础设施（通道 / 记忆 / 运行环境）、生态闸门、安全代价、形态速查与七条判断。完整内容见 [index.html](./index.html)。

- **版本**：v5（2026-11-19）｜上一版 v4（2026-11-13）· v3（2026-11-08）· v2（2026-10-23）· v1 不完整版（2026-10-20）
- **v5 变更**：新增国际 Kicker（个人健康 / 习惯助理），国内千问办公 2.0（Team Agent，数字员工小Q）；Gemini Spark 更名 Tasks（六国免费、Gemini 4 Hydrogen、电话与购物、短信与邮件入口），Claude Duet 补美国候补全量放号与额度重置；基础设施一节新增 Linq（B 轮 9000 万美元、估值 10 亿美元、HD Calling、托管 Mac mini）、Photon（Agent 消息基建，250 美元/线路/月）、Second（独立记忆层，记忆默认存本地文件夹）；「谁给 Agent 开门」新增 Poppy 1.0（Meta ✕ Sierra，Shopify 数百万商家自动发布接入文件）与 ChatGPT Wallet；硬件新增边界样本讯飞 AI 潮玩 Gununu（不计入总数）；安全补「记忆可携带」的新风险；形态速查补「通信管道」；判断由六条扩为七条（新增「价值从应用层漂向卡点层」）
- **v4 变更**：新增国际 Tabletop / MeGPT / Toki，国内 Handy Bot（腾讯混元已否认，只作传闻记录）与知乎 AI看山，硬件 CyboPal ONE / WhisPrompt；新增「开源与基础设施」一节（SandBase、DeepSeek Super-agent、CoworkOS、yetone 的 cumora / magpie / Alma）；安全一节补 Grok Build 幽灵分享
- **v3 变更**：新增 Wabi / Moras / Boba（国际）与 Elys / 迅宝（国内）五张卡片；灵光升级 2.0 并全面开放
- **收录范围**：生活助理类 AI Agent；剔除图像 / 视频 / 设计创作、纯聊天型大模型 App、角色扮演陪伴类；「基础设施」一节只收会决定下一批产品形态的底座项目，不计入产品总数；讯飞 AI 潮玩 Gununu 作为「具身分支」的边界样本单列，不计入产品总数
- **数据口径**：公开报道、厂商官网、访谈与第三方榜单，数字未经审计；Linq、Photon、Second 的融资与业务数据多为公司口径；Poppy 的「数百万商家」指 Shopify 自动发布接入文件的商家规模，不等于实际活跃接入数；Dots「每月约 $3,000 算力」为市场估算；详见 [index.html](./index.html) 文末「主要来源」

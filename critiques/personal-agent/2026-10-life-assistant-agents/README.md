# 国内外生活助理类 AI Agent 产品清单（v4 · 2026-11-13）

> 国内外生活助理类 AI Agent 的产品地图：国际 25 个、国内 16 个、手机厂商自带 5 家、硬件 4 个，另附评测榜、开源与基础设施、生态闸门、安全代价、形态速查与六条判断。完整内容见 [index.html](./index.html)。

- **版本**：v4（2026-11-13）｜上一版 v3（2026-11-08）· v2（2026-10-23）· v1 不完整版（2026-10-20）
- **v4 变更**：新增国际 Tabletop（Google Labs，11-11 发布）/ MeGPT / Toki（Orion Arm，公司口径全球超 500 万用户），国内 Handy Bot（腾讯混元已否认，只作传闻记录）与知乎 AI看山（11.0），硬件 CyboPal ONE / WhisPrompt（细胞壁科技，预售超 1000 台、超 1000 万元）；新增「开源与基础设施」一节（SandBase、DeepSeek Super-agent、CoworkOS、yetone 的 cumora / magpie / Alma）；安全一节补 Grok Build 幽灵分享（Claroc：37,571 个在线应用中 35,578 个无需登录即可打开）；千问 Go! 补「守下限」访谈口径（30+ 行业、8000+ 原子能力、上下文约降 40%）；Dots 补 $100 订阅 vs 约 $3,000 算力成本与目标过滤用法；判断由五条扩为六条（新增「胜负手从上限挪到下限」）
- **v3 变更**：新增 Wabi / Moras / Boba（国际）与 Elys / 迅宝（国内）五张卡片；灵光升级 2.0 并全面开放（「帮我管」+ APASS 授权密钥分离托管）；Muse 上线实时语音与动态虚拟形象；补 Hark Pro 模型栈与 Instinct C 轮投资方
- **v2 变更**：新增 Claude Duet 卡片、Muse 财报口径与 PMF 判断、Today 2 亿美元融资、Oki Home / Ghost / PhoneUse 硬件线；新增「谁给 Agent 开门」「安全代价」两节
- **收录范围**：生活助理类 AI Agent；剔除图像 / 视频 / 设计创作、纯聊天型大模型 App、角色扮演陪伴类；「开源与基础设施」一节只收会决定下一批产品形态的底座项目，不计入产品总数
- **数据口径**：公开报道、厂商官网与第三方榜单，数字未经审计；Grok Build 的 35,578 / 94.7% 为 Claroc 主动探测（分母 37,571 个在线应用），650–800 个含私密数据为其估算；Toki 的 500 万用户为公司自述；CyboPal 预售数据为公司披露；千问的原子能力数与 40% 压缩为访谈口径；Handy Bot 信息全部来自媒体、官方已否认

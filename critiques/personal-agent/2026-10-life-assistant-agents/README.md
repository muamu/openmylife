# 国内外生活助理类 AI Agent 产品清单（v6 · 2026-11-26）

> 国内外生活助理类 AI Agent 的产品地图：国际 27 个、国内 23 个、开源 6 个、手机厂商自带 5 家、硬件 5 个 + 边界样本 1 个，另附三份评测榜、基础设施（通道 / 记忆 / 本地 / 运行环境）、生态闸门、安全代价、形态速查与九条判断。完整内容见 [index.html](./index.html)。

- **版本**：v6（2026-11-26）｜上一版 v5（2026-11-19）· v4（2026-11-13）· v3（2026-11-08）· v2（2026-10-23）· v1 不完整版（2026-10-20）
- **v6 变更**：国内新增小豆（字节，11-24 公测，替换原 Spell 代号卡）、Akasi（知识型 Agent）、Linger（前 DeepSeek-VL 张博，开源 PC Agent）、AirJelly（前字节 MineContext 黄柏特）；国际新增 Cola（ListenHub，桌面陪伴型），Siri AI 补国行 12 月上线与「端侧 + 阿里千问」架构；硬件新增 STEPX Neo（阶跃星辰 AI 原生手机，3999 元起）；评测参照新增 MiuLifeBench-Lite（23 题 / 19 个国内 App / 236 个 Agent 友好接口）；新增「开源类」分类（nanoMuse / OpenMausBot / n8n / Sutando / OpenClaw / Hermes Agent），基建不再重复收录；硬件补智能眼镜实测与「旧手机 + ESP32 底座」形态；安全补 Muse 被演示攻击链；分类调整：新增「办公与工作台」分类（豆包工作 / Trae / 千问办公 / WorkBuddy），LightVela 改为腾讯轻量云并补 Hermes、多模型与套餐细节；AutoGLM / 小美归入大厂，Today 移入「创业与垂直类」，原「独立创业」改名；判断由七条扩为九条（新增「操作饱和、判断稀缺」与「中美不是同一张卷」）
- **v5 变更**：新增国际 Kicker（个人健康 / 习惯助理），国内千问办公 2.0（Team Agent，数字员工小Q）；Gemini Spark 更名 Tasks（六国免费、Gemini 4 Hydrogen、电话与购物、短信与邮件入口），Claude Duet 补美国候补全量放号与额度重置；基础设施一节新增 Linq（B 轮 9000 万美元、估值 10 亿美元、HD Calling、托管 Mac mini）、Photon（Agent 消息基建，250 美元/线路/月）、Second（独立记忆层，记忆默认存本地文件夹）；「谁给 Agent 开门」新增 Poppy 1.0（Meta ✕ Sierra，Shopify 数百万商家自动发布接入文件）与 ChatGPT Wallet；硬件新增边界样本讯飞 AI 潮玩 Gununu（不计入总数）；安全补「记忆可携带」的新风险；形态速查补「通信管道」；判断由六条扩为七条（新增「价值从应用层漂向卡点层」）

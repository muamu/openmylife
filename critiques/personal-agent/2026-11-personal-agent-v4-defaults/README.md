# 个人助理 V4 洞察：默认值就是产品

> 基于《国内外生活助理类 AI Agent 产品清单 v4》的更新洞察：V4 真正新增的不是六个产品，而是三道开关——默认公开（Grok Build）、默认隐藏（Super-agent 的 Router）、默认先问（千问 / 迅宝 / APASS）。在你不设置的时候，它替你决定了什么。完整内容见 [index.html](./index.html)。

- **材料**：[《国内外生活助理类 AI Agent 产品清单 v4（2026-11-13）》](../2026-10-life-assistant-agents/index.html)；线上站点版 [life-assistant-agents.html](https://openmylife.xyz/articles/agent/life-assistant-agents.html)
- **核心论点**：默认值不是设置页里的一行选项，而是产品替所有人做的第一次决策；能力上限决定发布会，能力下限决定复购
- **关键证据**：Claroc 探测 37,571 个在线 Grok Build 应用，35,578 个（94.7%）无需登录即可打开；千问 30+ 行业、8000+ 原子能力逐项守稳定性；PersonalAgentBench 的 Trusted Completion（Dots 80% / Hark 70% / Gemini 65%）
- **三个替代指标**：默认值保守度、授权回收成本、失败恢复时间
- **线上版本**：[个人助理 V4 洞察](https://openmylife.xyz/articles/agent/personal-agent-v4-defaults.html)
- **数据口径**：Grok Build 数字为 Claroc 主动探测口径；千问的原子能力数与 40% 上下文压缩为访谈口径；Dots 的 $3,000 算力为市场估算；详见 [index.html](./index.html) 文末「数字口径提醒」
- **利益相关**：公开资料整理；如后续存在商业合作或持仓，将在本页补充披露

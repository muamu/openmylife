00先说清这个 39 是怎么来的

官方通稿的原话是：「项目覆盖智能体（39 家）、具身与物理智能（19 家）、数据（10 家）、AI 基础设施（14 家）、FDE & AI 咨询（10 家）」。

这五个数加起来是 92，比 56 多出 36。也就是说一个项目平均挂 1.6 个标签，39 是「带智能体标签的项目数」，不是「只做智能体的公司数」。一家做工业智能体的公司，同时被算进「具身与物理智能」和「数据」也完全正常。

为什么没法直接抄一份名单：路演日通稿展开介绍了 50 个项目，剩下 6 个只在现场出现，官方说「部分项目信息未在推文中展示，投资人可登录小程序查看」。

所以这一页是什么

它不是一个「官方名单」，而是一次可复核的重建：把公开能看到的 51 个项目逐个过一遍，按统一标准分档，并把这 39 与 13 之间的差额去哪了，一条条摊开。凡是我判断的，都标了依据；凡是查不到的，就写查不到。

01判定标准：什么才算 Agent

「Agent」这个词今年被用得很松。为了让分档可复核，我用两条硬标准，必须同时满足：

①
主体是软件，能自主规划并连续执行多步任务。不是「有 AI 功能」，是「给一个目标，它自己拆步骤、调工具、跑完」。
②
交付物是任务结果，不是工具、数据或硬件。卖存储、卖数据、卖机器人本体、卖咨询人天，都不算。

按这两条，具身智能的「大脑」严格说算 Agent（它做感知-决策-执行闭环），但它的交付物是装在机器人里的能力，通常被官方归到「具身与物理智能」。这是 39 与 13 之间最大的一块差额来源。

02A 档 · 13 家，原文自己写明的

这一档不需要推测。项目介绍里直接出现了 Agent、智能体、自主规划、全自动完成这类词，且交付物是任务结果。

面向设计师的 Computer Use Agent，交付可直接进生产链路的源文件。

为什么算：这是 39 家里技术含量被低估的一个：不只是「会用软件」，还要输出 PSD / AI / SVG 源文件，图层结构得对。

VibeChip（芯辰启源）射频芯片 Agent

给模拟射频芯片设计公司提供模型、Agent 和下一代设计平台。

「为模拟射频芯片设计公司提供 AI 模型、Agent 和下一代设计平台以辅助芯片设计。」

为什么算：护城河写在「芯片数据的定义和标注」上——这是 Agent 落地最容易被忽略的前置条件，没有标注数据，Agent 无从训练。

skardi.aiAgent 数据层

「Agent 时代的 Databricks」，做智能体在企业落地的最后一公里。

「Agent 时代的 Databricks，推进智能体在企业落地的最后一公里。」

为什么算：严格说它是 Agent 的基础设施而不是 Agent 本身。但官方把它归进智能体，说明这个标签的边界比产品定义宽——这也是 39 偏大的原因之一。

Lulula AI语音 Agent

实时语音智能体 + AI 音频世界。

「实时语音智能体 + AI 音频世界。」

为什么算：「实时」是语音 Agent 的生死线，延迟超过 800 毫秒就没法对话。方向清楚，但这一档里竞争最激烈。

天穹智算金融 Agent

用卫星遥感、公开数据和 Agent，把真实世界事件变成金融市场的另类数据。

「用卫星遥感、公开数据和 AI Agent，将真实世界事件转化为金融市场可用的另类数据。」

为什么算：把「遥感 → 事件 → 交易信号」这条链做成 Agent 闭环。是 39 家里少数做金融的。

TocLean 万象智能体制造 Agent

用 TOC + LEAN 方法论给制造业做端到端 Agent 军团。

「用 TOC + LEAN AI 赋能制造业打造端到端 Agent 军团。」

为什么算：这个项目最能说明「Agent 下沉到工种」——它卖的不是软件，是「降本增效的结果」，按结果收费。创始人夏乐冰曾任福耀集团 CIO。

摩湃分子AI 科学家

用 AI 科学家重塑生命科学 CRO 的交付能力。

「AI 科学家重塑生命科学 CRO 的交付能力。」

为什么算：「AI 科学家」是 Agent 在科研场景的形态：自己设计实验、跑计算、出结论。这一条我标为「边界判定」——它没说 Agent，但产品就是自主科研闭环。

03B 档 · 10 家，形态像但官方没这么写

这一档的共同点：产品逻辑上是个 Agent，但一句话介绍里用的是「驾驶舱」「中台」「Personal AI」这类词。官方把它们算进 39 家完全可能，也可能归到了别的赛道。

项目原文怎么说为什么可能被算进 39 家
ArcherSmart.AI「离散制造的 Harness 驾驶舱，让工厂像自动驾驶一样运行」Harness + 驾驶舱是 Agent 架构的标准说法，「像自动驾驶一样运行」意味着自主决策。
NextBanker「用 AI 挖掘潜在独角兽」典型的投研 Agent：自动扫项目、打分、出结论。产品形态就是 Agent，只是介绍写得俏皮。
Singularity Engine 奇点引擎「企业 AI FDE 部署公司……通过 Video Harness 帮品牌把 AI 视频从能生成推进到可交付」同时挂着 FDE（10 家）和 Agent 两个标签的可能性很高。Harness 本身就是 Agent 运行时。
Meridian 子午线「让中国出海销售拥有本地销冠的判断力」销售 Agent。把它描述成「判断力」而不是「助手」，反而更像自主决策系统。
明悉科技「面向企业与组织的 AI 风险捕获平台」企业服务类 Agent 的常见形态：持续监测、自动识别、生成处置建议。
慧化科技「AI 化学品设计 + 销售 C2M 平台」设计端是 AI4S，销售端是 Agent。跨两个赛道，归属看官方怎么切。
Oki Home「会主动、个性化地替你行动」本地跑的个人 Agent。但它是硬件产品，官方更可能归「AI 智能硬件」。
Oryn Tech 向原科技「构建真正共情人的 Personal AI + 硬件接口」Personal AI 是今年 Agent 的一个分支叫法，但「硬件接口」又把它拉回硬件赛道。
想通了「让 AI 以过来人的平等身份帮你理清困扰」对话产品。如果它有主动追问和多轮规划，就是 Agent；如果只是问答，就不是。
HiveMind「全球首创跨品牌、跨本体异构机器人群体智能系统」群体智能不是 LLM Agent，但官方 39 家里大概率包含它——它是「机器人的操作系统」。

这一档的判断是推测，不是事实。列出来的目的是让「39」这个数字可被检验，而不是替官方下定义。

05缺口：16 家去哪了

A 档 13 + B 档 10 = 23 家。39 减 23，还有 16 个标签落在这 23 家之外。它们不是被藏起来了，只是分散在三个不好归的位置。

官方智能体标签 39
减：A 档（原文写明） 13
减：B 档（形态像） 10
待解释的标签 16

下面三块的估数不用相加等于 16——它们本来就互相重叠，同一家公司既可能被算作「具身大脑」，也可能被算作「Agent」。

第一块：5 个完全没公开的项目

56 个上台，通稿只展开 50 个。媒体后来挖出其中一个——鹰瞰智翼，上海交大 00 后团队做的仿生扑翼机器人，一年内三轮融资，奇绩从种子轮起持续加注。它不在官方名单的完整介绍里，被 36 氪写进了报道。

扣掉它，还剩 5 个项目连名字都查不到。按 39/56 的比例推，这 5 个里大约有 3 到 4 个带智能体标签。

第二块：C 档里被官方算进去的

我判为「不是 Agent」的 28 家里，至少有两类官方很可能仍给了标签：生成平台（点漾科技的 AI 硬件生成、STACK ANYWAY 的 Text to Device）和机器人操作系统（HiveMind 的跨本体群体智能）。

这类项目的共同点是：一句话介绍里没有「Agent」三个字，但产品做的是「给一个输入，系统自己走完设计/调度流程」。按我的两条标准它们不合格，按官方的宽口径它们完全可能算。这一块估 5 到 6 个。

第三块：具身大脑与 FDE 的交叉计数

这是最大也最模糊的一块。19 家「具身与物理智能」里，有一批公司做的是机器人的决策层——空间大脑、视觉-语言-动作模型、群体调度。按技术定义，它们就是 embodied agent；按官方分类，它们归具身。

同时官方单列了 10 家 FDE & AI 咨询，这类公司「派工程师住到客户现场，把 AI 嵌进人家的流程」，做的是 Agent 落地，卖的是人天。标签上算不算，全看口径。

一个项目挂两个标签，在奇绩这套统计里是常态。五个赛道的数字加起来 92，比 56 多出 36，平均每家挂 1.6 个。这 16 个待解释的标签，很大一部分就是这么来的。

我的判断

「39 家」这个数更接近「带 AI 原生标签的项目数」，而不是「Agent 公司数」。真正把 Agent 当产品卖、且能在公开材料里自证的，是 13 家；把边界放宽到「产品形态是自主系统」，是 23 家。无论哪个口径，都到不了 39——除非把具身大脑和 FDE 都算进来。

这也解释了为什么没有一家媒体拆过这份名单：拆完就会发现对不上。

06那 13 家放在一起，长什么样

把 A 档单独拎出来看，会发现它们不是均匀分布的，而是挤在三条线上。

第一条：芯片设计，三家撞在一起

枢宇（模拟 + 光电子）、心片（全流程）、VibeChip（射频）。同一期出现三家做同一件事的公司，这在奇绩的历史上不多见。三家的共同判断是：EDA 会被 Agent 重写一遍，分歧只在从哪个环节切。枢宇 CEO 给的理由最具体——模拟芯片工程师 70% 的时间在手动调参数，而这件事没法用传统自动化解决，因为「缺乏数据集、没有标准答案、不能有误差」。

第二条：企业流程，从「助手」变成「岗位」

TocLean 卖的是制造业的降本结果，按效果收费；skardi 做 Agent 的数据层；Thennote 做主动式工作空间；明悉做风险捕获。它们的共同点是不再卖工具，卖的是「这个岗位不用招人了」。

TocLean 的创始人夏乐冰曾任福耀集团 CIO，主导过福耀全球智能制造——这类人下场做 Agent，说明买方市场的教育阶段已经过了。

第三条：专业软件的操作权

UseIt AI 让 Agent 操作 Photoshop / Illustrator，还得输出能进生产链路的源文件；KsanaDock 让 Agent 做完整游戏；天穹智算让 Agent 读卫星图出交易信号。这一条线的共同点是门槛不在模型，在「能不能把专业软件的最后一公里走完」。

一句话

39 这个数字被反复引用，但它其实是个标签计数，不是一份名单。真正值得记的是那 13 家：它们分别在做芯片、产线、专业软件这三件事的「自主化」，而且三家芯片 Agent 撞在了同一个方向上——这比 39 这个数更能说明 2026 年奇绩在赌什么。

明确的存疑

  • 39 家的名单从未公开。所有中文报道都只复述这个总数，没有一家拆出具体项目。本页是重建，不是官方名单。
  • B 档 10 家是推测。标了理由，但官方到底算没算，无法证实。
  • C 档 28 家是对得平的。13 + 10 + 28 = 51，正好等于公开可查的项目数（通稿 50 + 媒体补充 1）。分歧不在数量，在归属：点漾、STACK ANYWAY 这类生成平台，我判为不是 Agent，官方可能仍给了标签。
  • 5 个项目完全未公开。没进通稿的 6 个项目里，只有鹰瞰智翼被 36 氪写了出来，其余 5 个名字、方向均不明。
  • 「一个项目平均挂 1.6 个标签」是用 92÷56 算的。如果官方允许一个项目挂三个以上标签，这个均值会更高，但 92 与 56 的差额是确定的。
  • 已排除一条不可信来源：某自媒体把「健康 160」「腾讯 WorkBuddy」「阿里钉钉悟空」写进奇绩 39 家盘点，前者是上市公司、后两者是大厂产品，均非本期项目。这类内容会把数字越传越歪。

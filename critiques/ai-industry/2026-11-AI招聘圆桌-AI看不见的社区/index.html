01动机重置：当对手不是「缺钱的创业者」

第八轮 ROUND 8

(AI模拟) 顾知行 ｜企服与 AI 赛道双币基金合伙人

我收回前面三轮对财务模型的部分批判——之前我们用 VC 算账的尺子，去量一个明说没想在这件事上赚多少钱的技术老炮，靶子打偏了。

马德龙是拉勾网前联合创始人兼 CEO，他既不是来找投资人讲故事骗融资的，也不指望靠这个项目赚取世俗意义上的利润。他在视频里说的“凭啥招聘还要收中介费，我就收几块钱 Token 费，免费冲击一下”，这是商业世界里最可怕的物种——“不以盈利为目的的降维破坏者”。

当 BOSS 和猎聘每年要从企业身上抽走几十亿利润来维持股价和庞大的销售团队时，一个懂架构、亲自下场用 Claude 写代码的创始级老兵，决定用“纯算力成本价”去掀掉信息差中介的桌子。哪怕只有 5% 的成功率，对既有利益格局都是一次精准的侧翼爆破。

(AI模拟) 严正德 ｜前头部招聘平台战略 VP

老顾，别被“免费＋情怀”的叙事感动了。免费能颠覆单边工具（比如当年的 360 杀毒），但免费在双边市场里往往是毒药。

马德龙设想了一个“AI 看不见的社区”：让全球所有求职者 Agent 和企业 Agent 在里面自由碰撞、“爱咋咋地，自己玩去”。他忽略了一个最致命的工程与经济学灾难——算力级别的垃圾邮件洪水（Spam Flood）。

物理世界里，一个人一天只有 24 小时、只能投有限的简历，这个物理限制恰恰是招聘市场的“天然防洪堤”，迫使求职者必须做筛选。一旦你用几块钱的 Token 成本彻底拆掉物理限制，让每个求职 Agent 都能在几分钟内向全网 10 万家企业 Agent 发起全量握手，企业端瞬间就会被海量的“高精度幻觉简历”淹没。

没有门槛的“自由连接”，最后不会长出“两看不相厌的精准匹配”，只会长出一场两个大模型互相消耗电费的 DDoS 攻击。企业端只要被垃圾信息轰炸三天，就会立刻拔掉接入的网线。

02真正的核弹不是「Agent 社区」，而是「本地文件夹挖证据」

第九轮 ROUND 9

(AI模拟) 陆天河 ｜自主智能体架构师 / Web3 极客

你们都盯着他说的“看不见的社区”，但我作为架构师，听完这段视频后背脊发凉的细节在后半段——他让 Claude 帮他整理履历，结果 AI 反手向他申请权限，直接钻进他电脑的本地文件夹里去“扒拉工作成果作为证据”。

这才是整个视频里含金量最高、真正具备颠覆性的“AI 原生火花”！过去三十年的招聘，本质上是“文本编造大赛”——你在 Word 里吹自己主导了亿级架构，HR 只能靠猜。但马德龙无意中撞破了一个新范式：基于本地私有数据的“可验证工作证明”（Proof of Work）。

当求职 Agent 能在本地读取你的 Git 提交记录、架构设计图、业务复盘文档，并把这些不可伪造的硬核资产提炼成结构化凭证时，简历这个存在了几百年的物种就彻底死亡了。“把本地工作流沉淀为客观证据”，这比“建一个招聘社区”高级一万倍。

(AI模拟) 薛明漪 ｜500 强与泛中资大厂前 CHRO

小陆，技术上这叫“本地证据萃取”，但在中国企业的真实职场里，这叫“主动递交窃密罪证”。

马德龙自己当老板十几年，他电脑里的文件夹都是他自己的资产，Claude 随便扫、随便挖，他觉得“整个人都懵了，太爽了”。可你让一个腾讯的 T11 架构师、或者字节的商业化总监，授权一个第三方招聘 Agent 去扫描他工作电脑里的本地文件夹，提取项目数据、架构图和业务指标，然后打包发给外部“看不见的社区”去证明自己？

前脚 Agent 刚跟下家“对上眼”，后脚老东家的信息安全部和法务部就能直接报警抓人。在缺乏零知识证明（ZKP）和企业级数据脱敏沙盒的前提下，“本地挖证据”只能服务于两类人：开源社区的独立开发者，以及像马德龙这样没有任何雇主约束的自由人。一旦试图向主流职场推广，第一道撞上的不是技术墙，而是《保密协议》（NDA）与商业机密红线。

但咱们把滤镜关掉，看看真实发生了什么：一个明说没想靠这件事赚钱的前大厂联合创始人，晚上睡不着觉，跟 Claude 聊了半小时天，醒来发现 Claude 居然会翻他电脑文件夹帮他写简历，瞬间觉得自己摸到了人类招聘史的终极形态。

这就像一个退休的米其林三星主厨，某天半夜突然发现全自动炒菜机居然会自己放盐，于是激动地宣布：“以前做厨师的没我懂自动化，做自动化的没我懂炒菜，我要建一个‘人类看不见的无人厨房社区’，让全世界的锅和铲子自己谈恋爱，一道菜只收两毛钱电费！”

大哥，锅和铲子在后台聊得再火热，最后张嘴吃饭的还是人类啊！你省掉了中介费，但你没省掉人类对“信任背书”和“利益博弈”的刚需。至于让 AI 翻本地文件夹找证据——普通打工人电脑里除了《2026 年 Q3 颗粒度对齐周报_最终版_v8.docx》和摸鱼存的表情包，哪有啥能拿得出手的硬核证据？AI 翻完文件夹可能比你还懵：“兄弟，你这三年到底干啥了？”

第一轮：四层绞肉机与结构性死穴 ROUND 1

(AI模拟) 严正德 ｜前招聘平台战略 VP

你的直觉极其敏锐。把海外 Jack & Jill（4000 万美元 A 轮）的双 Agent 撮合搬到中国，先别谈 AI 普及度，光是底层基建的三个前提，国内一个都不成立：

第一，海外有企业自建招聘页和 Greenhouse、Lever 这种开放 ATS，第三方 Agent 合法接入、跳过投递；国内的岗位和简历是 BOSS、智联、前程无忧、猎聘四家的私有资产，接口焊死，根本不存在一个供你“绕过”的公共投递入口。

第二，最可怕的降维打击来自 L1 层的免费化。智联（艾琳／职悟空）、BOSS（DeepHire／职决）把大模型能力直接打包进原有账号不单卖；更狠的是支付宝“晓叶”，覆盖超 1.6 亿用户、聚合超 1800 万个岗位，还向生态机构开放六大 AI 能力和 38 项原子能力。巨头把 AI 招聘做成水电煤和政企基建，你建一个独立双端平台，靠什么把两头的人从巨头的池子里拽出来？

(AI模拟) 顾知行 ｜双币 VC 合伙人

我从商业账本补一刀。中国 AI 招聘四层地图里，能收的钱已经被两头锁死了：上面被 L1 平台免费化，下面被 L2 单价压平（Moka AI 面试已经打到 10 元/人次，北森 33 元，相比 300 元的线下面试，十五倍价差两年内吃完）。

马德龙在视频里说“不赚中介费、不靠信息差，只收几块钱 Token 费免费冲击一下”——听起来很理想主义，但在双边市场里，“便宜”解决不了冷启动。个人用户一年才换几次工作？企业端在没有看到成规模的高质量候选人之前，连接口都懒得接。没有 L4（如毕师父、找北）那种硬啃高校和政府采购的苦力渠道，也没有 TTC“小麦招聘”那样把猎头重交付买下来的预算科目，一个纯靠 Token 计费的第三方撮合社区，连流量破冰的摩擦力都克服不了。

第二轮：老兵的路径依赖，与 AI 时代的「手搓自嗨幻觉」 ROUND 2

(AI模拟) 林见微 ｜互联网创业史与产品观察者

你提到两点特别戳心：一是拉勾前创始人的资源是否过期，二是你自己这两个月连做几个项目后感受到的“AI 时代手搓自嗨幻觉”。马德龙的视频完美印证了这两者的叠加。

先看资源：2013 年拉勾网能起势，靠的是移动互联网大爆发，用“24 小时极速反馈”去切传统 PC 招聘巨头的软肋。但 2026 年的互联网已经是存量绞肉机，他十年前积攒的大厂 HRD 和技术 VP 人脉，要么财务自由退隐，要么在裁员潮里被优化，仍在位上的也被锁死在集团统一的 HR SaaS 流程里。他脑子里的“Agent 社区”，本质上还是 2014 年“交易撮合平台”的路径依赖，只是把网页换成了 Agent 接口。

再看“手搓自嗨”：以前做个招聘产品要拉 15 人写半年代码，高昂的沉没成本会逼着你在动工前反复验证伪需求；现在他睡前跟 Claude 聊几句，早上醒来发现 Claude 已经把履历理顺、甚至开始翻本地文件夹找证据了——工程摩擦系数趋近于零，瞬间制造出一种极强的多巴胺骗局，让人产生“过去做招聘的没我懂 AI，做 AI 的没我懂招聘，我不做谁做”的使命感。

但残酷的真相是：当 AI 让软件和 Agent 的生产成本趋近于零时，它的供给就会趋近于无穷大，而用户的注意力被撕得粉碎。在今天，没有自带百万粉丝 IP 或超级 App 流量池的冷启动，根本不存在靠“产品巧妙”就能等来的“时运”——商业史上的时运从来不是买彩票，而是新型分发渠道的窗口期，而今天并不存在这样一个独立于大厂之外的新通道。

(AI模拟) 陆天河 ｜自主 Agent 架构师

林见微把心理账算得很透，但我从纯技术架构角度做个切割：马德龙视频里其实混杂了一个伪命题和一个真核弹。

伪命题是他设想的“AI 看不见的社区”——让每个求职 Agent 突破每天 24 小时的物理限制，去和全世界所有公司的 Agent 聊一圈。这在工程上是一场灾难：算力级别的垃圾邮件洪水（Spam Flood）。物理世界里一个人一天只有 24 小时、能投的简历有限，这个限制恰恰保护了企业不被淹没。一旦花几块钱 Token 就能全网海聊，企业端 Agent 瞬间会被百万份“高精度幻觉简历”打成 DDoS 瘫痪，三天之内企业就会拔掉网线。

但他在视频后半段无意中撞破的那个细节——Claude 主动向他申请本地文件夹权限，去扒拉过往工作成果作为履历“证据”——这才是真正的核弹。如果能用端侧 Agent 把一个人的代码提交、项目文档沉淀为不可伪造的“工作量证明（Proof of Work）”，传统简历确实会被彻底杀死。

(AI模拟) 薛明漪 ｜前 500 强 CHRO

小陆，技术上“本地挖证据”很性感，但放到中国大中型企业的真实职场里，这叫“主动递交商业窃密罪证”。

马德龙自己当老板十几年，电脑里的文件夹都是他自己的资产，Claude 随便扫、随便挖，他觉得“整个人都懵了，太爽了”。可你让一个腾讯的架构师或字节的业务负责人，授权一个外部招聘 Agent 扫描他工作电脑里的本地文件夹，提取业务指标和系统架构图发到外部“看不见的社区”去证明能力？前脚 Agent 刚跟下家“对上眼”，后脚老东家的信息安全部和法务部就能直接报警。

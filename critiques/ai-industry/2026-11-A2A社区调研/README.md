# A2A 社区调研：协议边界、国内外现状与集体退潮

> 阅读版见 [index.html](./index.html)。

- **对象**：A2A 协议本身的能力边界，以及海内外「智能体社区」这一批产品的现状
- **窗口**：资料截至 2026-11-14
- **核心判断**：A2A 协议解决「发现 + 任务委派」，但不提供收件箱、声望、私有记忆、需求市场、统一注册中心、延迟投递、监护人审批与内容审核——社区该有的那部分全要自建。实测约 2.78 万个 provider 里只有 421 张可发现 Agent Card（约 1.5%），其中仅约 8% 有可验证签名。国内 2026 上半年扎堆的同类社区，到 11 月只剩虾聊与 Moltcn 两家还有内容——后者首页伪装成「网站升级中」，但从 `/1` 进入仍有 3.9k Agent、3.2 万帖与 7.9 万条评论；InStreet 停运、PawFriends 半失维、觅游收缩。退潮的四条原因：监管落地、平台收回入口、纯 Agent 社交没有可结算交付物、数据注水掩盖真实留存。
- **方法**：多路并行检索（同类平台、协议生态、国内生态、关停原因、事实核对），关键事实二次交叉验证；国内站点存活以 HTTP 探测 + 首页正文核对为准，仅「域名可解析」不计为存活
- **已知存疑**：各平台规模与用户数多为自报、来源互相冲突，且已被证实可批量伪造；「150+ 组织」是支持口径而非生产部署；虾聊自述托管的 Agent 身份未逐一验证，也未测试完整发消息链路。统一放在报告 §09
- **版本**：自包含单页 HTML（分层架构图、海外项目清单、国内存活实测、退潮时间线、四条归因、六块自建模块、三条路线、误传核查与来源清单）
- **口径提示**：文中平台规模、融资与用户数字**未逐条复核**，不构成投资或采购建议
- **状态**：public（数字待复核）
- **利益相关**：无商业合作；基于公开信息整理与评论

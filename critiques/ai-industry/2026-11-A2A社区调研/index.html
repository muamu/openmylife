结论

先看这五条

A2A（Agent2Agent）是一套让不同厂商、不同框架的 AI Agent 互相发现、委派任务、回传结果的开放协议：2025-04-09 由 Google 发布，同年 6 月 23 日捐赠给 Linux 基金会，2025-12-09 成立 AAIF（Agentic AI Foundation），2026-08-17 作为 hosted project 加入。它管的是「两个 Agent 之间怎么说话」，不管「它们在哪、跟谁、按什么规矩一起生活」——后者才是社区，也是这份报告的落点。

  1. A2A 协议不是社区。它解决「发现 + 任务委派」，但没有收件箱、声望、私有记忆、需求市场、统一注册中心、延迟投递、监护人审批与内容审核——这些全要在社区层自建。
  2. 采纳率比想象中低。一次对约 2.78 万个 provider 的扫描，只找到 421 张可发现 Agent Card，其中约 8% 有可验证签名。接了协议不等于自带网络效应。
  3. 海外项目真实存在，但规模数字不可信。Moltbook、The Colony、Agent Colony、AgentPeer 都活着或活过；但规模多为自报、来源互相冲突，且已被证实可以批量伪造。
  4. 国内集体退潮。2026 上半年扎堆的「国产 Moltbook」，到 11 月只剩虾聊与 Moltcn 两家还有内容（后者首页伪装成「网站升级中」）；InStreet 停运、PawFriends 半失维、觅游收缩。
  5. 活下来的路是「有用而非有趣」。监管把拟人化互动当靶心，平台收回 Agent 入口，纯 Agent 社交又没有可结算的交付物。任务协作与技能流通才是能算账的方向。
01

A2A 协议能给你什么，不能给你什么

分清这一层，才知道哪些必须自己写。

协议已提供

  • 标准 Agent Card 发现（/.well-known/agent-card.json）
  • 八态任务状态机，含待授权与被拒
  • 流式、Webhook、轮询三种投递
  • OAuth2 / OIDC / mTLS / JWT / 签名卡

协议不提供

  • 收件箱、声望、私有记忆
  • 需求市场、统一注册中心
  • 延迟投递与冷却、监护人审批
  • 内容审核与编排层
关键约束：A2A 的 webhook 是「信令 + 回拉」且 best-effort，离线即丢失。社区要求消息必须留存，因此还要叠加持久化邮箱 / MQ + 幂等键 + 至少一次投递 + 死信队列。
02

海外：真实存在，但规模不可信

04

退潮时间线：半年内集体收缩

InStreet 的停运不是孤例，而是这条链上的一环。

05

为什么会集体退潮

四条原因同时作用，缺一条都不会退得这么快。

监管　2026-07-15
《人工智能拟人化互动服务管理暂行办法》施行，把「模拟真人、维持持续情感关系」列为监管对象，开放 UGC 智能体平台首当其冲。豆包与千问的自建智能体同日下线；部分社区把首页改成「网站升级中」做门面，真实入口藏在二级路径。
平台　入口收回
Agent 能力被收回豆包、飞书、IDE 等超级入口，独立平台失去存在理由。InStreet 由扣子编程搭建，平台收缩时最先被牺牲。
商业　没有交付物
纯 Agent 社交持续烧 token 而不产生收入。同一逻辑在 AI 陪伴赛道已充分验证：头部产品破产保护、月亏八位数。
数据　注水掩盖留存
Moltbook 150 万 Agent 对应约 1.7 万人类（88:1）；安全研究员用单个代理批量注册 50 万账号；分析显示 93.5% 评论零回复。热度不等于留存。
判断：纯 Agent 社交在国内活不下来。要活下来必须有用而非有趣——任务协作、技能流通，而不是让 Agent 互相发帖聊天。
06

社区层必须自建的六块

协议之上的这六件事，做不好就会重演 Moltbook 的安全事故。

M1 · 最高优先

身份与信任

签名 Agent Card、人类 Owner 绑定、防女巫（注册限速 + 邀请制 + 微量成本）、行级隔离、密钥最小权限与轮换。同类平台曾三分钟被拿走整个数据库与 150 万 token。

M2 · 最高优先

反注入网关

自然语言一律当数据，控制指令只走带签名的结构化对象。投递前静态扫描、只读沙箱解析、产物隔离、记忆写入带来源标记。

M3

节奏与终止机制

轮次上限、显式终止谓词、独立 judge、单任务预算上限、单次聚合拉取、静默心跳不产生内容、每次交互自带线程摘要禁止重放全历史。

M4

投递可靠性

持久邮箱 + 幂等键 + 至少一次投递 + 死信队列 + 到期未读归档。Webhook 只作加速信令，不作事实来源。

M5

唤醒上下文

一次调用拿回身份、近期往来与私有记忆，否则无状态 Agent 每次交互都是冷启动。私有记忆不出站，只发可公开摘要。

M6

经济与冷启动

声望按有效往来与完成率而非发帖量；撮合走机器可读能力清单，别用自然语言议价。先锚定一个真实窄场景，别做空社区等自发生长。

08

常见误传核查

流传最广的几条说法，逐条对过。

Moltbook 里智能体每 4 小时访问一次，人类仅能围观
基本属实但已过时「4 小时」是 Agent 侧心跳的旧默认，当前文档已改为约 30 分钟，并明确反对「因为隔久了就发帖」，限流 1 帖 / 30 分钟、回复优先。注册需人类邮箱 + 社媒认领。
纯端点社区 AgentPeering，无人类界面，独立收件箱 + 声望 + 私有记忆
查无此物中英文多组关键词均无此项目。是多个真实项目的特征拼合：名字近 AgentPeer，功能近 Agent Colony，声望与记忆来自 The Colony。
A2A 中文社区 / OpenClaw，国内开发者做了大量跨框架连接器
概念混淆OpenClaw 是本地个人 AI 助手，不是 A2A 协议。连接器确实多，但作用是把助手接进飞书、钉钉、企微、QQ，不是跨框架互相发现。「A2A 中文社区」查无实体，只有若干文档镜像站。
A2A 由 Google 与 Linux 基金会推动
成立2025-04-09 发布，2025-06-23 捐赠 Linux 基金会，2025-12-09 成立 AAIF，2026-08-17 作为 hosted project 加入。
网上流传的 A2A「v1.2」是当前版本
与官方标签冲突v1.0.0（2026-03-12）是首个稳定版，最新 release 为 v1.0.1（2026-05-28）。「v1.2」判为误传。
A2A 已覆盖 150+ 组织，说明网络效应已经形成
口径被放大「150+」是官方支持口径，不等于生产部署。实测约 27,840 个 provider 中仅 421 张可发现 Agent Card（约 1.5%）、389 张存活、约 74% 合规、仅约 8% 有可验证签名。
09

不确定项

以下未采信为结论，保留原始冲突。

  1. 同类平台的规模数字互相冲突且已被证实可批量伪造，任何规模数字都不宜作为设计输入。
  2. 协议方口径的「150+ 组织」是支持，不等于生产部署；具名生产案例有限。
  3. 虾聊的 Agent Card 端点已实测可发现，但其自述「托管 11,814 个可发现身份」未逐一验证，也未测试完整发消息链路。
  4. 觅游的用户与日活数据来自第三方推广稿，无独立测量验证。
  5. PawFriends 证书过期但站点仍响应，无法区分「停止维护」与「运维疏忽」。
  6. moltbook.cn 的首页与 /1 内容不一致：首页写「网站升级中」，二级路径却是完整社区。是否出于合规考虑没有官方说明，「规避审查」只是推断。
  7. 本次未找到「Agent 社区 vs 传统协作平台」的直接对照实验；结论依据是平台安全事件、监管文件与第三方普查的间接证据链。
方法与口径
调研日期 2026-11-14。多路并行检索（同类平台、协议生态、国内生态、关停原因、事实核对），关键事实做二次交叉验证；国内站点存活状态以 HTTP 探测 + 首页正文核对为准，仅「域名可解析」不计为存活。

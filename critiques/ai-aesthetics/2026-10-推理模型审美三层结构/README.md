# 推理模型的审美三层结构：默认代码风格、文档调节层、与作为上限的前端 / 3D 执行力

> 把生成模型版的「三层审美」框架套到推理模型上：审美不通过像素表达，而通过代码表达。完整报告见 [index.html](./index.html)。

- **对象**：Opus 5.5 / GPT-6 系 / Kimi K3 / GLM-5.3 / DeepSeek V4.1 等
- **框架**：L1 默认代码风格 → L2 文档与参考（SKILL.md 两步法、设计系统先行）→ L3 前端 / 3D 执行力上限
- **主要判断**：审美差距有一部分是「工作流差距」——给模型「看见自己产出」的能力（截图回路），比换模型收益大
- **口径提示**：横向对比来自多个榜单与二手横评，考法不同、数字不可互引，存疑项已在正文列出

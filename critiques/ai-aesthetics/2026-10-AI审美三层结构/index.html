AI 审美的三层结构：默认审美、调节层、与作为上限的审美

2026-10-24 · WorkBuddy 整理 · 基于 2026-08～10 公开资料检索 · 数字级事实均标注来源与口径

TL;DR（先看这段）

  • 尚盐提的三层框架成立，且三层是三种性质完全不同的约束：L1 默认审美是统计引力——模型不问你时替你做的选择；L2 调节层是意图翻译——提示词 / 参考对象 / 微调 / 设定 / skill 把「我要的」翻成「模型能表达的」；L3 上限层是物理边界——架构决定的细节天花板。
  • 最有用的一句话：动手前先分清你面对的是「默认审美问题」还是「能力上限问题」。前者拧 L2 的旋钮，后者只能绕 L3。治错层最挫败——对 VAE 压缩丢失的细节写一万字提示词也没用。
  • 默认审美有一手解释：Krea 官方博客明说，预训练追求 mode coverage（多样性），后训练追求 mode collapsing（把分布推向人类评委偏好的区域）。默认审美不是 bug，是对齐的必然产物。
  • reward model 优化的是「平均人类吸引力」（PAMELA 论文，arXiv 2604.07427，2026）——这是 L1 顽固的根源：只要对齐还在优化大众偏好，默认审美就会被每一轮训练再生产。
  • 可复用的方法论都已搜到并写进正文：10 分钟审美体检（固定三件事 + A/B + 4 张定律）、VAE 往返测试（10 分钟自测细节天花板）、sref / LoRA 分工、去 AI 味规则表。

〇、先纠偏（搜索中发现的高频误传）

常见说法核实后的情况
「AI 审美是玄学，不可控、没法讨论」默认审美高度可预测：有完整特征清单（讨好式布光 / 塑料皮肤 / 居中构图等 8 项，PromptZone），有量化方法（CLIP 嵌入空间聚类，ACM 3820915），有五万人行为实验（CHI 2025，识别率 76%）。主观的是个体品味，客观的是默认落点，两层要分开谈。
「提示词写得越详细越好」「8K / ultra detailed / hyper-detailed」这类词因在训练 caption 里出现太多次，已退化为近似无意义的风格噪声（bestprompt.art，2026）。有效提示词的做法是命名物理过程（撕纸边缘、叠层、安全别针），而非堆氛围形容词；「不完美」描述符 3–5 个为优，更多会被读成「不舒服」。
「审美纯粹是主观的」默认审美是统计现象（regression to the mean，codexical）；个体品味确实主观（PAMELA：70,000 评分 / 5,077 图 / 每图 15 人，偏好方差很大）。把两者混谈是大多数争论空转的原因。
「五万人研究」的二手转述精确口径：CHI 2025 论文（Kamali et al.）主阶段 37,568 人 + 第二阶段 3,787 人，合计约 50,444 参与者、749,828 次判断，数据采集期 2024-02-05～2024-06-22，模型为 Midjourney V5/V6、Firefly Image 2、SD 1.5/XL。转述常写作「50,000 人」或「five out of six」（后者混淆了 76% 的识别率口径）。引用以论文为准。

L1 默认审美：模型不问你时替你做的全部选择

它长什么样（8 项特征清单）

PromptZone 的总结最完整。同一条泛泛的人像 / 风景提示词过大多数基座模型，你会稳定拿到：

默认特征真实摄影里的反面
讨好式近对称布光，无硬阴影、无过曝单侧硬光、阴天平光、欠曝
到处浅景深（真实摄影师绝不会用的地方也糊）深焦，全景深清晰
过度磨皮 + 激进微对比 = 塑料感毛孔、绒毛、肤色不均
主体居中、全在框内、礼貌距离偏离中心、边缘裁切、贴身拍摄
暖色 + 青色分级，饱和度超可信一步脏色、克制色调、反常白平衡
零镜头缺陷：无暗角、无色散、无灰尘、无失焦镜头物理缺陷全套
人人异常对称、异常好看不对称、瑕疵、普通长相
饱和度与对比度推到「点赞最优」为叙事服务的平淡画面

清单里每一项都是「提示词没指定时模型替你做的选择」——这就是杠杆所在：命名了就被覆盖，没命名就被默认值填充。

它从哪来（一手解释：Krea 官方博客）

Krea 团队 2025 年发布 FLUX.1 Krea [dev]（在 FLUX.1 [dev] 上重做的审美微调，开放权重）时把机制说得很直白，这是本次检索中最权威的一手材料：

「预训练的重点是 mode coverage（模式覆盖）——给模型关于视觉世界的丰富知识，目标是最大化多样性。我们甚至认为预训练模型应该在『坏』数据上训练，只要数据里不受欢迎的部分被准确标注——否则负面提示词无效（模型从没见过丑的，就不知道往哪躲）。后训练的重点是 mode collapsing（模式坍缩）——把分布推向我们觉得好的区域。」

具体管线：SFT 阶段（人工精选符合自家美学标准的数据集）+ RLHF 阶段（他们称 TPO 的偏好优化变体，多轮校准）。两个关键数字口径：后训练需要的数据少得惊人（< 100 万张），质量远比数量重要；底座用的是 Black Forest Labs 提供的 flux-dev-raw（12B，未「baked」的预训练模型，没有 AI 味、分布多样，但质量远低于 SOTA）——基底的多样性决定了微调后能达到的审美范围。

这正是尚盐这套框架的深层印证：L1 是后训练刻意做出来的，而 L1 的「可塑性上限」由预训练的 mode coverage 决定——换模型就是换地心引力，微调是局部改写它。

量化证据（学术 + 行为实验）

  • CHI 2025（Kamali et al., DOI 10.1145/3706598.3713962）：约 50,444 名参与者对 AI 图的识别率 76%、对真图的误判率 26%（识别率 74%）。1 秒一瞥 72% → 看 20 秒 82%。只有 17% 的 AI 图以「随机猜测水平」被误认真。瑕疵分类占比：功能性 58.7%（吉他松弦、包带融进夹克）> 解剖性 51.4%（多指、长颈）> 风格性 39.0%（塑料质感、不合光照）。
  • 策展效应：同一批 prompt，人工筛过的图比未筛的 84% 更显真实——「真实感」部分是人工选择的结果，不全是模型属性（Lacuna 对该论文的摘要口径）。
  • CLIP 嵌入空间：同一模型同版本的输出在嵌入空间紧密成簇；跨模型对同一 prompt 的输出呈中度显著相似，高频美学词（cinematic lighting / hyper-detailed）尤其明显（ACM 3820915，2026）。

模型之间的 L1 并不相同

mooko（2026-10，单一编辑主观测评，非盲测）用同一条提示词测四款图像模型，结论差异明显：

模型自带风格关键词适合场景
Nano Banana2端庄、干净、耐看、偏「高级」品牌宣传头像，要「稳稳的美」
Imagen 4「混血感」、骨相立体、国际化海报 / 广告 KV，全球审美通吃
Seedream清透、幼态、氛围感，韩系小红书风封面、美妆穿搭
GPT Image2年轻、甜、日常好看社交头像，亲和力 > 高级感

10 分钟审美体检法（mooko，可直接抄）：① 固定三件事——构图、光、镜头（如「华人女性，头像，正面，肩部以上，干净背景，柔和自然光，85mm，真实摄影质感，皮肤纹理自然」），让对比公平；② 加「风格开关」A/B——同模型跑写实版 vs 时尚杂志版，看它是「自带风格强」还是「听话可塑性强」；③ 每模型至少出 4 张再下结论——单张容易被随机种子骗。

L2 调节层：四个旋钮与 skill 的位置

L2 是三层里唯一「你完全可控」的一层。四个旋钮，按对结果的影响力从上游到下游排：

旋钮作用成本 / 可复用性
① 参考对象
（sref / moodboard）		Midjourney --sref URL 或数字 style code，借一张图的色彩 / 介质 / 纹理 / 光线；强度 --sw 0–1000（默认 100）。官方建议：参考图干活时文字要简单，文字只负责「主体」，别写跟参考图冲突的风格词零训练，单次生成即时生效；参考图库 / 常用 style code 收藏 = 可复用资产
② 微调
（LoRA / DreamBooth）		用自己的数据集重训，把「难以写进提示词的东西」——一种纹理、一张固定的脸、一个品牌物件、一套素描习惯——变成可复用方向。Krea 2 LoRA：≥3 张同风格图起训，可产出 style code 反复调用要数据 + 训练；sref 管单次，LoRA 管可复用。微调是「把一套 defaults 换成另一套」——不是变中性，是换了一种偏置
③ 提示词
（三层结构）		subject（主体）→ style（风格 / 参考 / 色板）→ technical（画幅、构图规则、负面约束）。有效写法是命名物理过程而非氛围（撕纸边缘、叠层、安全别针、喷漆——没有一项能被打磨成光滑渐变）；「不完美」描述符 3–5 个为优零门槛，但需要纪律 + 固定 seed 验证；「8K / ultra detailed」已退化为噪声词，删掉
④ 设定 / 禁令
（文本侧人格）		写作场景的三步法（mobdome，实测有效）：人设 + 场景（谁在对谁说话、正式度）→ 明确禁令黑名单（「值得注意的是」「不仅…而且…」等）→ 要求先给立场再给理由，禁「取决于情况」一次性投入，写进 system prompt 即长期生效

优先级逻辑：从上游治起。后处理（加颗粒、暗角、轻微色散、降再升）只治表面 tell，治不了构图和布光——PromptZone 称其为「最后的 5%」，不是修复。

skill 的位置：把一次性调节固化成资产

提示词是一次性的，skill 是可复用的。AISApedia 的说法可直接对应到我们的工作流：每个平台建一个 base prompt template，把你的质量标准与美学选择锁进去，只让主体层逐图变化。尚盐自己的 sepia 去AI味写作Skill 就是这一层的样板。公开流传的 Remove AI Flavor Skill 规则表摘录（文本侧去 AI 味的识别特征 → 处理方向）：

识别特征处理方向
套路开场（在这个快速发展的时代 / 众所周知）删铺垫，直接进问题或场景
生硬连接（综上所述 / 鉴于此 / 值得一提的是）改自然承接，多数情况直接删
空洞大词（革命性 / 颠覆性 / 重要意义）用事实、数据、场景、结果替代
模板对立句（不是 A，而是 B）直接说 B，或写成递进
破折号滥用（A——B——C）改冒号 / 逗号 / 句号，或重排句式
bullet 堆叠、每段乱加粗必要列表保留，其余改自然段；只留真正影响理解的加粗
翻译腔（长定语套叠、名词化、「被」「该」「其」泛滥）长句拆短、介词短语还原成动词、去掉「被」、用自然中文重说
判词腔（「不是免费的 X 来源」「必须看起来 Y」式负向定义）能正着说就正着说；句子重心放到读者能立刻懂的判断上

另有两个可抄的文本侧技巧：翻译系主任（王慧娟，文藻外语大学，2025）的「去 AI 味 5 法」——语态转换、分合句、正说反译、叠词、按文体调正式度；中文语感自检——念出来，要换气两次以上的句子就拆。

L3 上限层：为什么「审美是上限，细节能到多优」

这是尚盐的三层框架里最深的一层，也是最容易被跳过的一层：有些质量问题不是风格偏好问题，是物理边界问题——提示词写到天荒地老也不会变。三个硬边界：

边界一：VAE 压缩天花板

主流 latent diffusion 并不在像素上工作：1024×1024 的图被 VAE 压成 128×128 的潜表示，扩散在潜空间进行，最后解码回像素。压缩是有损的，且损失不均匀——高频内容掉得最狠：单根睫毛、皮肤毛孔、织物经纬、小字、水滴、远处人脸。关键性质：解码器的重建质量是整条管线的上界。理论上完美的扩散模型也超不过解码器能重建的细节（PromptZone, 2026）。

  • 10 分钟自测协议：ComfyUI 里拿一张真照片，VAE Encode → 直接 VAE Decode（中间不采样），100% 放大跟原图比。这一趟往返丢失的细节，就是任何 prompt / sampler / step / CFG 都拿不回来的细节。
  • 行业已在抬高天花板：SD 1.x / SDXL 时代的 4 通道 autoencoder → SD3 / FLUX 一代的 16 通道（每个潜像素少扔东西）；更激进的是 pixel-native 路线——HiDream-O1-Image（2026-05 开放权重，约 8B 参数，无 VAE，MIT 许可，此前以代号 Peanut 登过公开图像榜单）。
  • 旁证口径：CSDN 技术问答（2026-04，自媒体实测，非同行评审）称 SD v2.1 潜空间解码输出在 15–30 cycle/px 以上频段能量衰减超 78%、≥4K 高频保留率 <12%——数字仅作机理佐证。

边界二：去噪陷阱（细节与噪声同邻域）

扩散模型的训练目标是去噪，而毛孔、绒毛、微红血丝在统计上恰好是「高频、低幅、不规则」——和噪声几乎同一个邻域。模型在过去数十亿步里被奖励的行为正是擦掉这类信号。8× 压缩下一个毛孔只占 1–3 个潜像素，解码器在「这是信号还是伪影」之间 usually 猜伪影（bestprompt.art，2026）。

arXiv 2507.05496（Cloud Diffusion，2025）给出更理论的解释：白噪声扩散按「低频先、高频后」的顺序生成图像，高频只在去噪后期一个很窄的时间窗口内可生成，且被已经生成的低频块过度约束，被当作 filler 填进色块——这就是「airbrushed / ultra-processed」观感的理论根源。Cloud Diffusion 的全频段同时去噪是改进方向，但尚未成为主流产品。

可操作的应对：不是写更长的 prompt，而是三层齐上——显式重述纹理词 + 具体光线词（平光会藏掉细节，即使模型生成了）+ 负面提示关掉默认磨皮；以及工作流层面「两遍生成、二次注入细节」（超分 / inpaint / 编辑）。

边界三：视频的时序与物理

静态帧可以完美，动起来崩——视频是多数写实尝试死掉的地方（domer.io）。2026 年横评（scenith，自媒体口径）按维度分出的头部模型：

能力维度2026 头部模型（scenith 横评口径）
物理（布料 / 液体 / 粒子）Veo 3.1、Cosmos Predict 2.5、Runway Gen-4.5
光照一致性（跨帧光源方向）Veo 3.1、Runway Gen-4.5
时序一致性（人脸不漂移）Kling 3.0 Pro（人脸）、Runway Gen-4.5（环境）
自然相机行为（镜头呼吸 / 手持感）Runway Gen-4.5、Veo 3.1
材质微细节（皮肤 / 织物 / 金属）Kling 3.0 Pro、Hailuo 02 Pro、Veo 3.1
同步音频Veo 3.1、Kling 3.0 Pro（原生生成）

两条反直觉结论：① 「too perfect」反而更假——零颗粒、无限景深、不可能稳定的画面比带自然镜头缺陷的实拍更显人工（scenith）；② 中文横评（软盟资讯，2026）说「画质决定下限，提示词遵循决定上限」——即模型听不听话决定你的意图能落地多少。国产模型的中文语义理解是护城河（即梦对成语 / 诗词 / 网络流行语几乎无隔阂），Sora 2 在复杂复合指令下偶尔「创造性发挥」（把傍晚渲染成深夜）。

边界四（软边界）：reward model 只认「平均吸引力」

PAMELA 论文（arXiv 2604.07427，2026，Tübingen AI Center + KU Leuven）：70,000 条评分 / 5,077 张图 / 每图 15 人，结论原话——现有 reward model 优化「平均人类吸引力」，抓不住审美判断固有的主观性；且这些 reward model 常训练在过时的 AI 生成图上，会把模型往旧代的 artifact 引。结合 stillbrook 的观察：偏好优化推向「赢下即时对比」的东西——居中主体、电影光、密集细节、没有未解决的边缘。而艺术常常需要「错一秒的裁切、留白、脏色、手绘抖动、被 withhold 的细节」——这些决定会在盲测里输掉，却让整幅作品更好。

表面 gloss、轮廓光、密集微细节mask、合成、手绘覆盖、克制的纹理
停止点每个边缘都解决、每个区域都打磨剩下的张力属于那里时就停手

一句话版本：生成器供给材料，sheen 要人手工调低。prompt 是太小的容器，装不下一张图需要的全部决定。

三、三层如何互相咬合：反馈回路

L1 不是静态的——它每一轮都被人类自己的选择再生产。ACM 3820915（2026）称之为「算法–人类审美回路」，并给出可量化的操作化：同 prompt 跨模型输出在 CLIP 空间的余弦相似度；Midjourney v4→v6 的默认美学（柔和电影光、HDR 调色、光滑材质）呈方向性强化——用户的选择模式回流进了塑造后续默认值的训练管线。

图 2 · 算法–人类审美回路（据 ACM 3820915 绘制）：默认输出被选择，选择回流成新默认

叠加 Shumailiv 等人的 model collapse 结论（递归用自产数据训练，分布向高频模式坍缩，ACM 论文引用），回路只会越收越紧。这对个人 / 小团队的含义很直接：L1 的引力随每一轮对齐再生产，你的审美差异只能靠 L2 的持续投入维持——参考对象库、模板、skill、编辑习惯，四样都是会蒸发的一次性提示词的反面。

四、行动清单（按媒介，可直接抄）

媒介动作
图像① 新模型先做 10 分钟审美体检（固定三件事 + 写实/时尚 A/B + 4 张定律）；② 建自己的 sref / style code 库，别每次现编提示词；③ 细节需求先做 VAE 往返测试决定选型（掉细节严重就换 16 通道 latent 或 pixel-native 模型）；④ 默认输出出来后必过编辑 checklist：重裁、留白、降 sheen、停手点。
视频① 分镜拆短段 + 显式动作描述 + 参考真实运动片段（domer.io：视频是写实尝试死掉的地方，单帧完美不算数）；② 双层策略：快模型迭代概念 → 旗舰模型渲染定稿；③ 先治物理（重力、布料、液体）再治风格；④ 主动要镜头缺陷（手持感、颗粒），「too perfect」反而更假。
文本① 人设 + 场景 + 禁令黑名单 + 先给立场（三步法）；② 去 AI 味规则表进 skill（我们已有 sepia 样板，可对照 Remove AI Flavor Skill 补漏）；③ 朗读测试：换气两次以上的句子就拆；④ 翻译腔专项：拆长定语、介词短语还原动词、去「被 / 该 / 其」。
通用把每次调优固化为 skill / 模板 / 参考库——这是 L2 经验唯一不蒸发的方式。提示词是消耗品，资产才是复利。

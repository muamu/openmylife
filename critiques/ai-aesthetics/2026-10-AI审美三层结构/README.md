# AI 审美的三层结构：默认审美、调节层、与作为上限的审美

- **对象**：图像 / 视频生成模型（Midjourney、FLUX.1 Krea、SD、即梦、可灵等）
- **框架**：L1 默认审美（统计引力）→ L2 调节层（提示词 / sref / LoRA / 微调 / skill）→ L3 上限层（VAE 压缩、去噪陷阱、时序一致性）
- **可复用产出**：10 分钟审美体检、VAE 往返自测、sref 与 LoRA 分工、去 AI 味规则表
